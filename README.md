#  Databricks SQL ETL Pipeline

## Project Overview
This project demonstrates an end-to-end ETL pipeline using SQL in Databricks to transform raw data into clean, analytics-ready data.

##  Architecture
Bronze → Silver → Gold

- **Bronze Layer**: Stores raw data
- **Silver Layer**: Cleans and processes data
- **Gold Layer**: Final data for reporting

## 📂 Data Used
- customers.csv
- orders.csv

## ⚙️ Process
1. Load raw data into Bronze tables  
2. Clean data in Silver layer  
3. Join and prepare final dataset in Gold layer  

##  Tools Used
- Databricks
- SQL
- GitHub

## 📈 Outcome
- Clean and structured data ready for analysis
