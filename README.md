# 🚀 Databricks SQL ETL Pipeline

## 📌 Project Overview
This project demonstrates an end-to-end ETL pipeline using SQL in Databricks. It transforms raw CSV data into clean, structured, and analytics-ready datasets using a multi-layer architecture.

## 🏗️ Architecture
Bronze → Silver → Gold

- **Bronze Layer**: Stores raw ingested data
- **Silver Layer**: Cleans, filters, and transforms data
- **Gold Layer**: Final curated dataset for reporting and analytics

## 📂 Data Used
- customers.csv
- orders.csv

## ⚙️ ETL Process
1. Load raw data into Bronze tables  
2. Perform data cleaning and transformations in Silver layer  
3. Join datasets and prepare final output in Gold layer  

## 🛠️ Tools & Technologies
- Databricks SQL
- SQL
- GitHub

## 📊 Output
- Cleaned and structured dataset ready for analysis  
- Final dataset created using JOIN operations  

## 🚀 How to Run
1. Upload CSV files to Databricks  
2. Execute SQL scripts  
3. Verify data in Bronze, Silver, and Gold tables
